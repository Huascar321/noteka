## ADDED Requirements

### Requirement: Deadlines como calendario mensual

Projects SHALL mostrar Deadlines como calendario de fecha civil de fin para proyectos cargados, incluyendo completados y una lista separada de proyectos sin fecha, con navegación y aviso de datos parciales.

#### Scenario: Preparar proyecto desde un día

- **WHEN** la persona solicita crear desde un día
- **THEN** se prepara un proyecto con esa fecha de fin sin guardarlo implícitamente
