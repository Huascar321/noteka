# Verificación de rueda de mouse

El 27/10/2026 se añadió suavizado para eventos de rueda con señal discreta y una preferencia local `noteka.smooth-wheel.v1`. La selección predeterminada es activa; `off` devuelve el scroll al sistema. Movimiento reducido desactiva el suavizado durante esa preferencia del sistema. No hay cambios de formato del workspace.

`npm run build` pasó con cero errores/advertencias Svelte, con el aviso previo de chunk mayor a 500 kB. `node --experimental-strip-types --test tests/smooth-wheel.mjs` aprobó dos pruebas de clasificación y almacenamiento. `node scripts/headless-smooth-wheel-smoke.mjs` y `NOTEKA_TEST_BROWSER=webkit node scripts/headless-smooth-wheel-smoke.mjs` aprobaron 20 checks cada uno en Chromium y WebKit con workspace sintético. Cubren acumulación, inversión, controles, zoom, entrada horizontal y precisa simulada, límites anidados, movimiento reducido, búsqueda de ajustes, persistencia, fallo de almacenamiento y limpieza. En una rueda simulada por el navegador, las muestras intermedias/finales fueron 3/120 px en Chromium y 8/120 px en WebKit; el panel exterior desplazó 120 px tanto con el ajuste apagado como encendido al llegar al borde interior.

La señal es heurística: WheelEvent no identifica de forma inequívoca el dispositivo. Eventos sin señal suficiente siguen nativos y algunos gestos precisos podrían parecer pasos de rueda. La preferencia permite desactivar el listener; este listener es cancelable y puede cambiar el desempeño del compositor. La prueba automatizada no sustituye la evaluación con el mouse físico, WKWebView nativo ni plataformas Windows/Linux; el ajuste debe validarse en esos entornos antes de afirmar una mejora universal.

La documentación de [scroll-behavior de MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/scroll-behavior) distingue scroll programático del manual; la discusión de [UI Events](https://github.com/w3c/pointerevents/issues/596) documenta la ausencia de una identificación fiable de mouse frente a trackpad en WheelEvent. Se conserva la propagación nativa en límites y no se interceptan zoom, eje horizontal, selects, áreas de texto o entradas numéricas.
